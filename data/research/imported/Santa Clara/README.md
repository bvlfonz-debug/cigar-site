# Santa Clara — Database Research Batch 19

Researched against the live catalog at https://cigar-site.vercel.app/brands/santa-clara/ on 2026-09-30.

## Unusually strong source material: the manufacturer's own size charts

This Mac folder is mostly marketing collateral rather than per-vitola product photos - but a few of the
images are Santa Clara's own official "Vitolario" (vitola/size chart) graphics, which I viewed directly.
That means the vitola names and dimensions below come straight from the manufacturer rather than being
reconstructed from retailer listings, which is about as reliable as sourcing gets for this project.

## 2 gap-fill supplements

- `_santa-clara-1830-additional-vitolas.json` — site lists only "San Andrés Robusto" (5x50). The chart adds
  9 more: Churchill, Gran Bolero, Number 1, Number 3, Number 4, Number 5, Number 6, Quino TT, Bolero - the
  line's essentially the full catalog was missing.
- `_gran-santa-clara-additional-vitolas.json` — site lists only "Special Edition Magnum" (6x60) for Gran
  Santa Clara, a different product. The chart for the line's "Gran Reserva" sub-line adds 3 more: Robusto,
  Number Four, Quino.

## 1 new line

- `santa-clara-1830-50th-anniversary-triple-maduro.json` — a limited 50th-anniversary "Triple Maduro"
  release. **Flag worth your attention:** the Mac folder has two separate official chart graphics for this -
  one banded in English ("50th Anniversary Triple Maduro"), one in Spanish ("Medio Siglo Triple Maduro") -
  both showing identical vitolas (Robusto 5x50, Toro 6x50). I've treated them as the same release marketed
  under two names/bands rather than two distinct products, but that's an inference from the chart imagery
  alone, not independently confirmed elsewhere - worth double-checking if you have more context.

## Sourcing

Primarily the manufacturer's own Vitolario chart graphics found in the Mac photo collection itself - no
external web research was needed for the core vitola data in this batch, since the charts are about as
authoritative a source as exists.
