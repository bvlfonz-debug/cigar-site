# Henry Clay — Database Research Batch (Altadis USA reorganization, part 14)

Checked against the site's live brand index on 2026-10-11 — **Henry Clay is confirmed completely absent**.

## Brand background

Founded in the 1840s by Spanish immigrant Julián Álvarez Granda in Cuba, named after the US statesman. A
historic Havana brand nationalized post-Revolution; the US trademark passed through Henry Clay & Bock Co.
Ltd. and later Consolidated Cigar Corporation (acquired by Altadis). No official Altadis USA brand page was
found this session — all positioning language in the JSON is retailer paraphrase, not a verified primary
source statement.

## 4 new lines

- `henry-clay.json` — the core line. **Flagged**: wrapper is inconsistent across sources (Connecticut
  Broadleaf maduro confirmed on specific SKUs vs. Ecuadorian Sumatra/Connecticut Shade on some brand-overview
  pages) — likely different sub-SKUs or eras, not resolved into one spec.
- `henry-clay-rustic-cheroot.json` — a cheroot format (closed footer, pigtail cap) launched 2018, single
  size only (5.625x38).
- `henry-clay-war-hawk.json` — launched 2019, the first Henry Clay product with an Ecuadorian Connecticut
  Shade wrapper. **Flagged**: Corona's size conflicts between the 2019 launch article (5.5x44) and a current
  JR Cigars listing (5.0x44) — possibly a size change over time, not resolved.
- `henry-clay-war-hawk-rebellious.json` — **confirmed to be a genuinely distinct limited-edition blend**
  (Nicaraguan puro, different factory/blender) from the regular War Hawk line, not just a size variant within
  it. Single vitola only (Toro 6x54), a 2020 limited run of 1,200 boxes.
