# Classic — Database Research Batch (2026-10-11)

## Context

The Mac folder "Classic" (24 photos: Connecticut/Cuban-seed/Cameroon/Maduro wrappers across Churchill/Corona/Robusto/Torpedo/660/Sixty vitola names) does not match any brand on the site's full 112-brand index under that name.

## Outcome: could not be confidently identified

This batch produced **no database entries** — only a single flag file, `_classic-UNRESOLVED.json`, documenting the research attempt.

The best lead found is **United Cigar's "Classic" line** (Classic Cuban / Classic Connecticut / Classic Maduro — a value-tier Dominican Republic cigar), which matches 3 of the 4 photographed wrapper types and 4 of the photographed vitola names (Corona 6x44, Robusto 5x50, Torpedo 6x50, Churchill 7x50). However, this lead has two significant gaps that prevent treating it as settled:

1. **No Cameroon-wrapper variant** of United Cigar's Classic line was found in any source, despite several Mac photos (`Classic_Cameroon-*`) implying one exists.
2. **No "660"/"Sixty" (6x60) vitola** was found documented for that line, despite multiple Mac photos across several wrapper variants implying this size exists.

Other candidate brands with similarly-named "Classic" lines were checked and ruled out or left inconclusive: AVO Classic, Aladino Classic, Quorum Classic, Gurkha Classic — none matched the full 4-wrapper/6-vitola pattern in the photos.

## Why nothing was published

Given the Cameroon-wrapper and 660/Sixty-vitola gaps, and that the United Cigar identification itself is only medium-confidence (not a direct, fully corroborated match), publishing a "United Cigar Classic" entry would have required guessing specs not found in any primary source. Per this project's no-fabrication policy, nothing was added — the full reasoning, the partial lead, and what was and wasn't confirmed are recorded in `_classic-UNRESOLVED.json` for a future follow-up pass (e.g., checking United Cigar's own site/catalog directly, or an Internet Archive snapshot of it).

## File handling

No Mac file renames were performed — the folder's actual brand identity remains unresolved.

Primary sources checked: Blind Man's Puff, The Cigar Authority, Cigar Dojo. See `_classic-UNRESOLVED.json` for the full source list and reasoning.
